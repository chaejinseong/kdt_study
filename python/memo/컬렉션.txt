컬렉션(list, tuple, set, dict) 메서드
1) 리스트
   리스트명.메소드명()
   .append(값)
      - 값을 리스트의 맨 뒤에 추가 해준다
   .insert(인덱스, 값)   
      - 값을 해당 idx에 추가해준다
   .extend([])
      - 리스트와 다른 리스트를 연결해준다.
   .remove(값)
      - 값을 삭제한다. (값이 없을 때는 오류가 발생)
   .pop(인덱스)
      - 해당 인덱스의 요소를 삭제한다
   .sort()
      -요소를 오름차순 정렬해준다(리스트 자체를 내부적으로 정렬)
   .sort( , reverse = True) 
      - 요소를 내림차순 정렬해준다
   sorted()
      - 리스트의 정렬된 복사본을 반환

   len() : 리스트의 길이(요소의 갯수) 알려준다
2) 튜플의 메서드
   .count(값)
      - 해당 값이 몇 개인지 값을 반환한다
   .index(값)
      - 해당 값의 인덱스 번호를 알려준다
딕셔너리의 메서드
   - 키(key)와 값(Value)가 항상 한쌍으로 저장된다
   - key값의 중복이 불가능하다

   .keys() : key값들만 모여있는 새로운 컬렉션
   .values() : value값들만 모여있는 새로운 컬렉션
   .items() : (key, value) 튜플들이 담겨있는 새로운 컬렉션
제어문
1) if문
   - 특정 조건의 만족 여부에 따라 실행
   if, if~else, if~elif~else

   if 조건식1:
      조건식1을 만족하면 실행할 문장
   elif 조건식2:
      조건식1을 만족하지 않고,
      조건식2를 만족하면 실행할 문장
   ...
   elif 조건식3:
      조건식1을 만족하지 않고,
      조건식2를 만족하지 않고,
      조건식3을 만족하면 실행할 문장
   ...
   else:
      조건식1, 조건식2를 모두 만족하지 않을 때
      실행할 문장




반복문
   - 같은 코드를 조건이 만족되는 동안 여러 번 실행하기 위한 문법

1. for문
   for 변수명 in 집합(문자열, 리스트, 튜플, 레인지, 세트, 딕셔너리):
      print(변수명)

range() 함수
   - 필요한 만큼의 숫자를 만들어내는 유용한 기능을 가진 함수
   - range(시작값, 종료값, 스탭값)

기타 제어문
   1) break 문
      - 처리 흐름을 강제로 종료하고 그 블록을 나가는 구문
   2) continue 문
      - 블록 내의 처리를 건너뛰고, 블록의 앞 위치로 돌아가서
      즉시 다음 반복문을 실행하는 구문
   단, if문에 감싸져 있다면 if문을 감싸고 있는 블록은 인식하지 않는다.
   
   3) pass 문
      - 실행할 코드가 없는 것으로 다음 행동을 계속해서 진행하는 구문
      - 지금 당장 사용하지 않지만, 코드 동작을 사용하기 위해 사용한다.
      
2. while문
   - 특정 조건을 만족하는 동안(True) 반복해서 수행한다
   ex)
   while 조건식:
      반복할 문장
