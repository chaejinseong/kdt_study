숫자의 내장함수(9개)
   1) abs()
      - 전달한 인수(정수 또는 실수)의 절대 값을 반환한다
   2) divmod(값1, 값2)
      - 전달된 두 인수를 나누어서 몫과 나머지를 한 쌍의 결과로 반환한다
   3) float()
      - 전달된 인수(실수 또는 문자열)을 실수로 만들어서 반환한다
      - 전달된 인수가 없을 때 0.0을 반환한다
   4) int()
      - 전달된 인수(숫자 또는 문자열)를 정수로 만들어서 반환한다
      - 전달된 인수가 없을 때 0을 반환한다
   5) max()
      - 전달된 인수 중 가장 큰 값을 반환한다
   6) min()
      - 전달된 인수 중 가장 작은 값을 반환한다
   7) pow(10, 2)
      - 전달된 두 인수의 거듭제곱을 반환한다
   8) sum()
      - 전달된 리스트나 튜플과 같은 반복 가능한 객체의 합을 반환한다
      - 숫자가 아닌 값을 전달하면 오류가 발생한다
   9) round()
      - 전달된 인수를 이용해서 반올림한 값을 반환한다
      - 전달된 인수가 하나면 정수로 반올림한 값을 반환한다

시퀀스 내장함수(5개)
   1) enumerate()
      - 리스트와 함께 사용하며, 지정된 요소와 해당 요소의 인덱스가 튜플 형태로 출력된다
   2) range()
      - 전달된 인수 값에 따라서 시퀀스 자료형의 데이터를 생성하는 함수
      - for문에서 주로 사용되며, 원하는 횟수만큼 for문 내부의 실행문을 실행한다
   3) len()
      - 전달된 객체의 길이(항목수)를 반환하는 함수
   4) sorted()
      - 전달된 반복 객체의 오름차순 정렬 결과를 반환하는 함수
   5) zip()
      - 전달된 여러 개의 반복가능한 객체의 각 요소를 튜플로 묶어서 반환하는 함수
      - 전달된 반복가능한 객체의 길이가 서로 다르며 길이가 짧은 반복 가능한 객체를 기준으로 동작한다

*문자열 메서드
   1) .count()
      - 문자열 내부에 특정 문자열의 개수를 반환한다
   2) .find()
      - 문자열 내부에 포함된 특정 문자열을 찾고, 문자열이 나온 첫번째 index 값을 반환한다
      - 단 찾으려는 문자가 없다면 -1을 반환한다.
      - 찾는 방향에 따라 .rfind() 메서드도 존재한다
   3) .index()
      - .find()메서드와 같은 역할을 하며, 사용방법도 동일하다
      - find는 찾으려는 문자열이 없다면 -1을 반환하고, 값이 없을 때 오류가 발생한다
   4) .upper()
      - 모두 대문자로 값을 바꿔 반환한다
   5) .lower()
      - 모두 소문자로 값을 바꿔 반환한다
   6) .capitalize()
      - 첫글자는 대문자로 변환하고, 나머지는 소문자로 변환한 결과를 반환한다.
   7) .join()
      - 인수로 전달된 반복가능한 객…
