지역변수
   - 함수 내부에서 선언된 변수이며, 함수에서만 사용이 가능하다.

전역변수
   - 함수 밖에서 선언한 변수, 전역에서 사용이 가능하다.

global문
   - global문을 사용하면 함수 안에서도 전역변수의 값을 수정이 가능하다



------------------------------------------------------------------------


모듈(module)이란?
   - 함수, 클래스, 변수 등을 하나의 파일에 모아 놓은 코드의 집합을 의미하며,
   모듈을 사용하면 코드를 재사용하고, 코드의 구조를 더 효율적으로 관리하기 위해 사용된다.
   - 파이썬의 파일(.py)은 모듈이 될 수 있다.
   
모듈의 사용
   import문
   ex)
      from 파일명 import *(asterlisk)
	# * -> all이라고도 부른다, 모든것 이라는 의미
      *는 모든 것을 의미한다.

   특정 함수만 import
      from 모듈 import 함수
      from 모듈 import 함수1, 함수2

경로
    - 프로그래밍 언어, 운영체제 등에서 컴퓨터의 파일을 찾아가는 방법을 경로라고 하며
    - 절대 경로와 상대 경로로 구분하여 사용 할 수 있다.
    
    / :  최상위 폴더의 경로
    ./ : 현재 폴더 경로
    ../ : 현재 폴더 위 경로
    
절대 경로, 상대 경로
    
상대 경로 :
    - 상대적인 경로 현재 폴더를 기준점으로 기입하는 경로 방식
    
절대 경로 : 
    - 시작 위치부터 끝까지 전부 기입하는 경로 방식
