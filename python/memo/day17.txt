SQLAlchemy ORM(Object Relational Mapping)
   - SQLAlchemy는 Python 환경에서 사용하는 대표적인 ORM이다.
   SQL을 직접 작성하지 않고, Python 클래스(Class)와 객체(Object)를 기반으로 
   데이터베이스 테이블을 자동으로 매핑해주는 기술이다. 
   즉, 객체와 DB 테이블을 1:1로 연결하여 Python 코드만으로 데이터를 조회, 저장, 수정, 삭제할 수 있다.

주요 기능
   1. ORM 매핑: Python 클래스를 테이블 구조와 자동 매핑
   2. CRUD 자동화: session.add(), query(), update(), delete() 등을 통해 SQL 자동 실행
   3. DB 독립성(Database Abstraction): MySQL, PostgreSQL, Oracle, SQLite 등 다양한 DB 지원
   4. 관계 매핑(Relationship): relationship()을 통해 Join 관계 자동 처리
   5. SQL 표현식 지원(Core): 복잡한 SQL도 Python 코드 형태로 작성 가능

대표 ORM 프레임워크
   - JavaScript / TypeScript: Prisma, Sequelize, TypeORM
   - Python: SQLAlchemy, Django ORM
   - Spring: JPA

장점
   - Python 기반으로 직관적인 DB 제어 가능
   - 다양한 데이터베이스 지원
   - ORM + 순수 SQL(Core) 모두 사용 가능
   - 객체 지향 방식으로 유지보수 용이
   - 대규모 프로젝트에서도 활용 가능

단점
   - 초기 설정과 구조 학습 난이도가 있음
   - 복잡한 관계 설정 시 코드가 길어질 수 있음
   - ORM 사용 시 복잡한 SQL 최적화가 어려울 수 있음
   - 세션(Session) 관리 개념을 이해해야 함

SQLAlchemy 옵션

mapped_column()
    - 의미: 테이블 컬럼 정의 (2.0 권장 방식)
    - 기존 Column() 대신 사용 권장

Integer, String, DateTime
    - 의미: 컬럼 데이터 타입 지정

Mapped[int], Mapped[str]
    - 의미: ORM 타입 힌트 지정 (SQLAlchemy 2.0 표준)

primary_key=True
    - 의미: 해당 컬럼을 기본 키(Primary Key)로 지정

autoincrement=True
    - 의미: 정수형 컬럼 값을 자동 증가 설정

unique=True
    - 의미: 컬럼 값의 중복을 허용하지 않음

nullable=False
    - 의미: NULL 값을 허용하지 않음

default=datetime.utcnow
    - 의미: 기본값으로 현재 시간 자동 저장

ForeignKey()
    - 의미: 다른 테이블의 기본 키를 참조하는 외래 키 설정

relationship()
    - 의미: 테이블 간 관계(1:N, N:1 등) 설정
    
      
SQLAlchemy 결과 처리 메서드

1. scalar()
- 첫 번째 컬럼 값만 반환
- 결과가 없으면 None
- 결과가 여러 개 있어도 첫 번째 값만 반환
- 예제: value = session.execute(select(User.id)).scalar()

2. scalar_one()
- 첫 번째 컬럼 값 반환
- 결과가 정확히 1개여야 함
- 없으면 NoResultFound 예외
- 2개 이상이면 MultipleResultsFound 예외
- 예제: value = session.execute(select(User.id).where(User.id==1)).scalar_one()

3. scalar_one_or_none()
- 첫 번째 컬럼 값 반환
- 결과가 0개 또는 1개일 때만 허용
- 2개 이상이면 MultipleResultsFound 예외
- 결과가 없으면 None 반환
- 예제: value = session.execute(select(User.id).where(User.id==2)).scalar_one_or_none()

4. one()
- 전체 row 객체 반환
- 결과가 정확히 1개여야 함
- 없으면 NoResultFound 예외
- 2개 이상이면 MultipleResultsFound 예외
- 예제: user_obj = session.execute(select(User).where(User.id==1)).one()

5. one_or_none()
- 전체 row 객체 반환
- 결과가 0개 또는 1개일 때만 허용
- 2개 이상이면 MultipleResultsFound 예외
- 결과가 없으면 None 반환
- 예제: user_obj = session.execute(select(User).where(User.id==2)).one_or_none()

6. all()
- 전체 row 객체를 리스트로 반환
- 결과가 없으면 빈 리스트 []
- 예제: users_list = session.execute(select(User)).scalars().all()
