PostgreSQL이란?
   - PostgreSQL의 시작은 캘리포니아 버클리 대학의 포스트그레스 프로젝트에서 시작된 POSTGRES 패키지에서 파생되었다.
   엔터프라이즈급 성능과 높은 확장성을 자랑하는 오픈 소스 객체-관계형 데이터베이스 관리 시스템(ORDBMS)을 의미한다.

PostgreSQL의 장점 
   1) 강력한 확장성: 사용자가 직접 데이터 유형, 함수, 연산자 등을 정의하여 맞춤형 데이터베이스를 구축
   2) 높은 표준 준수: SQL 표준을 엄격하게 준수하여 호환성이 뛰어나고 복잡한 쿼리 처리에 강함
   3) 데이터 무결성: 강력한 트랜잭션(ACID) 지원을 통해 데이터의 일관성과 정확성을 보장
   4) 다양한 데이터 타입 지원: JSON, XML 등 비정형 데이터는 물론, 지리 공간 데이터 처리에도 탁월
   5) 무료 사용: 완전한 오픈 소스 라이선스를 따르므로 비용 부담 없이 상용 서비스에도 자유롭게 활용 가능

PostgreSQL의 설치(Docker 정석 - 실무에서는 볼륨 추가)
   > docker run --name postgres-db -e POSTGRES_USER=hr -e POSTGRES_PASSWORD=1234 -e POSTGRES_DB=myapp -p 5432:5432 -d pgvector/pgvector:pg16
pgavector 확장
   > docker exec -it postgres-db psql -U hr -d myapp -c "CREATE EXTENSION IF NOT EXISTS vector;"
   
도커 환경 bash로 접속
> docker exec -it postgres-db psql -U hr -d myapp

hr계정을 슈퍼계정으로 만들어 권한 부여
> alter role hr with superuser;
