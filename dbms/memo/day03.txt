정규화의 개념(DB Normalization)
   - 하나의 엔터티에 많은 속성을 넣게 되면 조회 시 많은 데이터를 조회 된다. 따라서
   최소한의 데이터만을 하나의 엔터티에 넣는 식으로 데이터를 분해하는 과정이다.
   - 중복을 제거하고 데이터 모델의 독립성을 확보한다
   - *이상현상을 줄이기 위한 설계 기법이다
   - *논리적 데이터 모델링 수행 시점에서 고려되며 제 1정규화부터 제5정규화까지 존재한다
   
이상현상(Abnormality) - 삽살개
   - 정규화를 하지 않아 발생하는 현상(삽입이상, 갱신이상, 삭제이상)
   1) 삽입 이상
      - 특정 인스턴스가 삽입할 때 넣지 않아도 되는 데이터를 반드시 입력하게 만드는 이상 현상
   2) 삭제 이상
      - 해당 인스턴스를 삭제할 때 다른 데이터가 연쇄적으로 삭제되는 현상
   3) 갱신 이상
      - 어떤 값을 수정할 때 수정되지 않거나 다른 데이터가 같이 갱신되는 현상
      
      
정규화의 단계
1) 제 1정규화(1NF)   - 도메인 원자성
   - 도메인이 원자값일 때
   
   |이름|구매상품|
   |----|-------|
   |홍길동| 샴푸, 린스|
   |장보고| 우유, 치즈|
               
         1차 정규화 후
         
   |이름|구매상품|
   |----|-------|
   |홍길동| 샴푸|
   |홍길동| 샴푸|
   |장보고| 우유|
   |장보고| 치즈|
   
2) 제 2정규화() - 부분 함수종속 제거
   - 완전 함수 종속을 만들도록, 부분 함수 종속을 제거해야 한다
   * 완전함수종속 : 키가 모든 컬럼을 결정 짓는다.
   즉 PK가 가능한 키가 2개라면 분리한다
   
   |학번|학생명|강의명|강의실|학과장|
   |---|------|-----|------|------|
   |001|홍길동| 코딩 |C강의장|김과장|
   |002|장보고| 미술 |D강의장|최과장|
   
         2차 정규화 후
   - 학번에 따라 학생이 결정된다
   - 하지만 학번에 따라 강의명이 결정되지 않는다.
   - 강의명에 따라 강의실이 결정된다
   - 따라서 완전 종속 관계 (학번 - 학생명) : 해당 테이블의 PK
   - 부분종속 관계 (강의명 - 강의실) : PK가 아닌데 PK의 역할
   
   |학번|학생명|강의명|
   |---|------|------|
   |001|홍길동| 코딩 |
   |002|장보고| 미술 |
   
   |강의번호|강의명|강의실| 강사 |
   |-------|------|------|------|
   |  001  | 코딩 |C강의장|김강사|
   |  002  | 미술 |D강의장|최강사|


3) 3차 정규화 - 이행종속 제거
   - PK가 B를 직접 결정하지 않고, A를 거쳐서 B
   - PK가 모든 컬럼을 식별하는 것이 아니라 강의명을 통해서 강사를 알 수 있다
   
   |학번|학생명|강의명|
   |---|------|------|
   |001|홍길동| 코딩 |
   |002|장보고| 미술 |
   
   |강의번호|강의명|강의실| 강사 |
   |-------|------|------|------|
   |  001  | 코딩 |C강의장|김강사|
   |  002  | 미술 |D강의장|최강사|

   3차 정규화 후
   
   
   |학번|학생명|강의명|
   |---|------|------|
   |001|홍길동| 코딩 |
   |002|장보고| 미술 |
   
   |강의번호|강의명|강의실|
   |-------|------|------|
   |  001  | 코딩 |C강의장|
   |  002  | 미술 |D강의장|
   
   |강의명|  강사  |
   |------|--------|
   | 코딩 | 김강사 |
   | 미술 | 최강사 |
   
   
4) 4차 정규화 - 다중 종속성 제거
   - 여러 컬럼들이 하나의 컬럼을 종속시키는 경우 분해하여 제거한다.

5) 5차 정규화 - 조인 종속성 제거
   - 조인에 의한 종속성이 발생하는 경우 분해하여 제거한다.
   
반정규화(역정규화, 비정규화)
   - 데이터 베이스의 성능 향상을 위해 정규화를 위배하는 행위
   즉, 중복을 허용하여, 조인을 줄이며 정규화를 수행하지 않는 것을 의미한다.
   - 특정 범위에 데이터만 자주 처리하는 경우


조건식
   - 참 또는 거짓 둘 중 하나가 나오는 식

   >, <      : 초과, 미만
   >=, <=      : 이상, 이하
   =      : 같다
   <>, !=, ^=   : 같지 않다
   AND      : 둘 다 참이면 참
   OR      : 둘 중 하나라도 참이면 참
   NOT      : 참을 거짓으로, 거짓을 참으로

※ 위 연산자들은 WHERE 절에서 사용 가능하다.


/*
 * 
 * LIKE: 포함된 문자열 값을 찾고, 문자의 개수도 제한을 줄 수 있다.
 * 
 * %: 모든 것
 * _: 글자 수
 * 
 * 예시
 '%A' : A로 끝나는 모든 값(NDFLSNJFA, 123NFJA, ...)
 'A%' : A로 시작하는 모든 값(AA, ANDKFS, AJD, ...)
 'A__' : A로 시작하며 3글자인 값(ABC, AAA, ADD, ...)
 '_A' : A로 끝나며 2글자인 값(FA, CA, DA, ...)
 '%A%' : A가 포함된 값(APPLE, BANANA, TASK, ...)
 * 
 * */
